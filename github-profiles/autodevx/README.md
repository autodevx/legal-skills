# Autodev Tecnologia

**IA e automação para operações jurídicas no Brasil.**

Construímos infraestrutura de dados e inteligência artificial para departamentos jurídicos, escritórios de advocacia e equipes de Legal Ops — com foco no ecossistema processual brasileiro (CNJ, PJe, eSAJ, TRFs, TRTs).

### Open Source

- **[legal-skills](https://github.com/autodevx/legal-skills)** — Skills de IA para o dia a dia de jurídico corporativo

### O que fazemos

- Pipelines de dados jurídicos (processos, andamentos, publicações)
- Automação de fluxos de Legal Ops e compliance
- Análise inteligente de contratos, contingência e risco
- Dashboards e relatórios para controllers e diretoria

### Stack

`Python` `FastAPI` `Neo4j` `NestJS` `MongoDB` `PostgreSQL` `LLMs` `Claude Skills`
